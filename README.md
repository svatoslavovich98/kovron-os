# KOVRON OS

Система управления заказами, производством и финансами компании KOVRON.

PWA-приложение для учёта заказов на изготовление автомобильных ковриков.

## Быстрый старт (демо-режим)

Приложение работает сразу без базы данных — на встроенных демонстрационных данных.

```bash
# 1. Установить зависимости
cd kovron-os
npm install

# 2. Создать файл переменных окружения
cp .env.example .env.local

# 3. Запустить
npm run dev
```

Откройте http://localhost:3000

## Подключение Supabase (реальные данные)

1. Создайте проект на [supabase.com](https://supabase.com)
2. В SQL Editor выполните содержимое `supabase/schema.sql` (скопируйте текст файла целиком и вставьте в редактор — не имя файла)
3. Затем так же выполните содержимое `supabase/functions.sql` (балансы и атомарное получение оплаты)
4. Выполните содержимое `supabase/storage.sql` (хранилище фотографий заказов и чеков)
5. Создайте пользователей через Supabase Auth (Dashboard → Authentication → Users)
6. Укажите ключи в `.env.local`:

```env
NEXT_PUBLIC_DATA_MODE=supabase
NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJ...
SUPABASE_SERVICE_ROLE_KEY=eyJ...
```

7. Перезапустите `npm run dev`

## Фотографии заказов

Фотографии сохраняются в публичном Supabase Storage bucket `order-media`.
Поддерживаются JPEG, PNG, WebP, HEIC и HEIF размером до 12 МБ. В заказе можно
хранить одну раскладку, до четырёх фотографий салона и от одной до четырёх
фотографий готовых ковриков. Фото готового изделия добавляет швея перед
переводом заказа в статус «Готов».

3. Добавьте переменные окружения в Vercel Dashboard
4. Vercel автоматически соберёт и развернёт приложение

## Каталог лекал

Раздел «Лекала» подключён напрямую к готовому каталогу:
**https://lekalakovron.netlify.app/** — 156 марок, 5723 лекала с фотографиями.

Каталог встроен как есть (`src/app/(app)/templates/page.tsx`), поэтому поиск,
фильтры по типу (Пол / Багажник / Правый руль) и превью фото работают
без изменений. Чтобы обновить каталог — обновите сайт на Netlify,
в приложении изменения появятся сразу, пересборка не нужна.

Если каталог перестанет открываться внутри приложения, проверьте, что Netlify
не отдаёт заголовок `X-Frame-Options: DENY` (по умолчанию не отдаёт).
Кнопка со стрелкой в шапке всегда открывает каталог в отдельной вкладке.

## Генерация иконок PWA

```bash
npm install -D sharp
node scripts/generate-icons.js
```

Или создайте PNG-файлы вручную из `public/icons/icon.svg` (192x192 и 512x512 px).

## Установка на телефон

1. Откройте приложение в браузере на телефоне
2. **iPhone**: нажмите «Поделиться» → «На экран Домой»
3. **Android**: нажмите три точки → «Установить приложение»
